# Feuerwehr Schrietz Wiehl - Website

Offizielle Website für die **Feuerwehr Schrietz Wiehl** Roblox-Roleplay-Community.

## Features
- Modernes Dark-Design mit feuerwehrroten Akzenten.
- Responsive Navigation für Smartphone, Tablet & PC.
- Vollständiger Abspann mit Cinematic Animation.
- Impressum & Datenschutz als bearbeitbare Vorlagen.

## Upload auf GitHub Pages
1. ZIP-Datei entpacken.
2. Neues GitHub-Repository erstellen.
3. Alle Dateien direkt auf GitHub hochladen.
4. Unter **Settings > Pages** die GitHub Pages aktivieren.
